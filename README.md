# Kesley Psicologa

Site institucional preparado para executar no Lovable com a estrutura React, TanStack Start e Vite esperada pela plataforma.

O site visual fica em `public/landing` e e exibido pela rota principal React. Essa organizacao preserva integralmente o HTML, o CSS, o JavaScript, os videos e os frames da animacao original.

## Desenvolvimento local

```bash
bun install
bun run dev
```

## Verificacao de producao

```bash
bun run build
```
